1. Sets and Set Operations

Set ka matlab hai well-defined objects ka collection. Set ko generally curly brackets { } ke andar likhte hain.
Example 1: Set banana
A = {1, 2, 3, 4, 5}
Yahan A ek set hai aur 1,2,3,4,5 uske elements hain.

Union

Union ka matlab dono sets ke saare different elements ko combine karna. Symbol: A ∪ B
Example 2:
A = {1,2,3} B = {3,4,5} A ∪ B = {1,2,3,4,5}
3 repeat kyon nahi hua?
Kyuki set me duplicate element normally ek hi baar likha jata hai.

Intersection

Intersection me sirf common elements aate hain. Symbol: A ∩ B
Example 3:
A = {1,2,3} B = {2,3,4} A ∩ B = {2,3}
2 aur 3 dono sets me common hain.

Difference

Example 4:
A = {1,2,3} B = {2,3,4} A - B = {1}
A me jo hai lekin B me nahi hai → 1.

2. Determinants

Determinant ek square matrix se calculate hone wali single numerical value hai. 2×2 matrix ke liye:
A = [a b c d] det(A) = ad - bc
Example 1:
A=[2 3 4 5] det(A) =(2×5)-(3×4) =10-12 =-2
Determinant = -2
Example 2:
A=[1 2 3 4] det(A) =(1×4)-(2×3) =4-6 =-2
Example 3:
A=[5 0 2 3] det(A) =(5×3)-(0×2) =15
Determinant = 15
Example 4:
A=[1 2 2 4] det(A) =(1×4)-(2×2) =4-4 =0
Agar determinant 0 hai, matrix singular hoti hai.

3. Inverse of Matrix

Matrix A ka inverse A⁻¹ hota hai jab:
A × A⁻¹ = I
2×2 matrix ke liye:
A=[a b c d] A⁻¹ = 1/(ad-bc) [d -b -c a]
Example 1:
A=[2 1 1 1]
Step 1:
det(A) =(2×1)-(1×1) =1
Step 2: Diagonal elements interchange:
[2 1 1 1] → [1 -1 -1 2]
Step 3: Divide by determinant 1:
A⁻¹=[1 -1 -1 2]
Example 2: Agar det(A)=0 ho:
1/det(A) =1/0
Possible nahi.
Inverse exist nahi karta.
Example 3:
A=[1 2 3 5] det=1×5-2×3 =5-6 =-1
Determinant non-zero hai, isliye inverse exist karta hai.
Example 4:
A=[3 0 0 2] det=6 A⁻¹=[1/3 0 0 1/2]

4. Solution of Simultaneous Linear Equations

Do ya zyada equations me common variables ki values find karna simultaneous equations solve karna hai.
Example 1: Solve:
x + y = 5 x - y = 1

3+y=5 y=2
Answer: x=3, y=2
Example 2:
2x+y=7 x+y=5
Second equation subtract:
(2x+y)-(x+y)=7-5 x=2
Ab:

x=2, y=3
Example 3: Matrix method

AX=B
[1 1] [x] = [5] [1 -1] [y] [1]
Then:
X=A⁻¹B
Calculation ke baad:
x=3, y=2
Example 4:
3x+y=10 x+y=6
Subtract:
2x=4 x=2

UNIT 3 — Probability Theory

1. Basic Concepts of Probability

Probability kisi event ke hone ki possibility ko measure karti hai. Probability ki value 0 se 1 ke beech hoti hai.
P(E)= Favourable Outcomes ------------------- Total Outcomes
Example 1: Coin Coin ke 2 outcomes:
{Head, Tail}
Head favourable = 1
Total = 2
P(Head)=1/2
Probability = 0.5
Example 2: Dice me 6 Total outcomes = 6
P(6)=1/6
Example 3: Dice me even number Even outcomes:
{2,4,6}
Favourable = 3
Total = 6
P(Even)=3/6=1/2
Answer = 1/2
Example 4: Dice me number > 4 Favourable:
{5,6}
P(>4)=2/6=1/3

2. Conditional Probability

Agar hume pata ho ki event B already occur ho chuka hai, to event A ki probability ko conditional probability kehte hain.
P(A|B)=P(A∩B)/P(B)
Example 1: Ek deck se card nikala. Given hai card red hai. Probability ki card heart hai? Red cards = 26
Hearts = 13
P(Heart | Red) =13/26 =1/2
Answer = 1/2
Example 2: Class me 20 students hain. 10 boys hain. Un boys me 4 coding karte hain.
P(Coding | Boy) =4/10 =0.4
Example 3:
P(A∩B)=0.2 P(B)=0.5 P(A|B)=0.2/0.5 =0.4
Answer = 0.4
Example 4: Agar P(A∩B)=0.3 aur P(B)=0.6:
P(A|B)=0.3/0.6 =0.5

3. Bayes' Theorem

Bayes theorem new evidence milne ke baad probability update karne ka method hai. AI aur machine learning me ye bahut important hai.
P(A|B) = P(B|A)P(A) ---------------- P(B)
Example 1: Medical Test Type Example Maan lo: Disease hone ki probability:
P(D)=0.01
Disease wale person ka positive test:
P(+|D)=0.90
Disease na hone par false positive:
P(+|not D)=0.05
P(+):
P(+) = P(+|D)P(D) + P(+|not D)P(not D) =0.90×0.01 +0.05×0.99 =0.009+0.0495 =0.0585
Ab Bayes:
P(D|+) = 0.90×0.01 -------------- 0.0585 =0.1538 approximately
Positive test ke baad disease probability ≈ 15.38%
Example 2:
P(A)=0.2 P(B|A)=0.8 P(B)=0.4 P(A|B) = (0.8×0.2)/0.4 = 0.16/0.4 = 0.4
Answer = 0.4
Example 3:
P(A)=0.3 P(B|A)=0.6 P(B)=0.5 P(A|B) =(0.6×0.3)/0.5 =0.36
Example 4: AI Spam Filtering Email spam hone ka prior probability hai. Kuch words "free", "offer" etc. evidence dete hain. Bayes theorem:
Prior probability + evidence → Updated probability. Isi concept se probabilistic spam classification ki ja sakti hai.

Standard Deviation

2. Distance Measures

Distance measures do points/vectors ke beech difference ya distance ko measure karte hain.

Euclidean Distance

d = √[(x₂-x₁)² + (y₂-y₁)²]
Example 1: A=(1,2)
B=(4,6)
d=√[(4-1)²+(6-2)²] =√[3²+4²] =√[9+16] =√25 =5
Distance = 5
Example 2: A=(0,0)
B=(3,4)
d=√(3²+4²) =√25 =5

Manhattan Distance

d=|x₂-x₁|+|y₂-y₁|
Example 3: A=(1,2)
B=(4,6)
d=|4-1|+|6-2| =3+4 =7
Manhattan Distance = 7
Example 4: A=(2,3)
B=(5,5)
d=|5-2|+|5-3| =3+2 =5

3. Introduction to Derivatives

Derivative batata hai ki function ki value input ke change ke saath kitni rapidly change ho rahi hai. Simple language me: rate of change.
If: f(x)=x² then: f'(x)=2x
Example 1:
f(x)=x² f'(x)=2x
x=3 par:
f'(3)=2×3 =6
Rate of change = 6
Example 2:
f(x)=x³ f'(x)=3x²
x=2:
f'(2)=3×2² =12
Example 3:
f(x)=5x f'(x)=5
Yani function ka rate of change constant 5 hai.
Example 4:
f(x)=7 f'(x)=0
Constant ki value change nahi hoti, isliye derivative 0.

4. Basic Optimization Concepts

Optimization ka objective hota hai kisi function ko maximum ya minimum karna. AI/ML me loss function ko minimize karna common objective hai.
Basic idea: Start with function ↓ Derivative nikalo ↓ Derivative = 0 solve karo ↓ Candidate point milega ↓ Check karo minimum/maximum.
Example 1: Minimum
f(x)=x²
Derivative:
f'(x)=2x
Minimum ke candidate ke liye:
2x=0 x=0
Function:
f(0)=0
Minimum point = x=0
Example 2:
f(x)=x²+4x+3
Derivative:
f'(x)=2x+4
Set zero:
2x+4=0 2x=-4 x=-2
Function value:
f(-2) =(-2)²+4(-2)+3 =4-8+3 =-1
Minimum value = -1
Example 3: Simple AI idea Suppose loss:
L(w)=w²
Derivative:
dL/dw=2w
Agar w=5:
dL/dw=10
Gradient positive hai, so optimization algorithm w ko lower direction me move kar sakta hai.
Example 4: Gradient Descent Basic update:
w(new)=w(old)-η × gradient
Suppose:
w=5 gradient=10 η=0.1
Then:
w(new) =5-(0.1×10) =5-1 =4
New w = 4
Yani algorithm loss ko reduce karne ki direction me parameter update karta hai.
